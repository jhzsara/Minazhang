# MinaZhang

Polished mobile-first front-end for a private 1-to-1 subscription chat service.

## Current status
This repository contains the front-end foundation. Real authentication, database, payment, identity-verification and realtime chat integrations should be connected before production use.

## Domain
The CNAME is set to `minazhang.online`. Configure the DNS records at your domain registrar and enable GitHub Pages in repository settings.

## Security
Never commit passwords, API keys, payment secrets, passport images, IBANs, or other sensitive credentials to this repository.
